# AI 美妆客服 · 智能坐席工作台

单文件 AI 美妆客服坐席工作台，零依赖，双击 `index.html` 即可运行。

## 打开方式

直接双击 `index.html`，或用浏览器打开：

```
index.html
```

## 功能

- **实时会话**：客户消息、AI 建议回复、发送 / 引用 / 表情、快捷注入事件
- **情绪与满意度引擎**：情绪值随对话连续变化（-2.4 ~ +2.4，7 档表情），满意度独立演化
- **话术小助手**：可拖动浮层，按客户原话 + 情绪 + 意图实时生成推荐话术
- **色号卡弹窗**：3D 翻面卡，不选 8 秒自动收起，不遮挡主界面
- **AI 建议总开关**：话术小助手头部与左下角导航栏各一个金属手轮开关，双向联动，关闭后不再生成推荐 / 自动弹窗
- **日夜主题**：顶部 bloom-switch 切换粉白 / 深玫紫
- **演示控制**：自动播放、事件注入、重置演示数据

## 技术

- 单文件 HTML + 内嵌 CSS / JS，无任何外部依赖
- CSS 自定义属性做主题 token，`body.night` 整套覆盖
- 数据为模拟数据，仅用于演示
